# YouTube Music audio resolver

`ytaudio` — небольшой Python-сервис для HexWave Radio. Он получает ID записи из уже проверенного музыкального каталога, с помощью yt-dlp находит временный HTTPS-адрес аудио и возвращает его радиоботу. Сам сервис не скачивает и не проксирует аудиоданные, не хранит cookies и не принимает произвольный URL от слушателя.

## Контракт

| Метод | Ответ |
| --- | --- |
| `GET /health` | `{ ok }` |
| `POST /resolve` с `{ videoId }` | `{ url, expiresAt, mimeType, itag, durationMs, filesize }` |

Резолвер отбрасывает трансляции, записи с неправдоподобной длительностью и видеоформаты. Для audio-only выбирается m4a. MIME-список синхронизирован тестом с YouTube Music адаптером в `apps/discord-radio/src/providers.ts`; прямой URL никогда не является доказательством, что это музыкальный трек. На HTTP 403 и недоступных записях сервис возвращает различимые коды ошибки, чтобы радио не зацикливалось на одном источнике.

Сборка сервиса описана в `ytaudio/Dockerfile`; Compose подключает его к радиоботу как отдельный контейнер. Локальная проверка: `python -m pytest ytaudio/test_resolve.py`. Использование yt-dlp и источника музыки подчиняется условиям, описанным в [правах на музыку](../docs/licensing.md).
